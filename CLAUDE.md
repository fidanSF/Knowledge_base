# Протокол памяти Claude

Этот репозиторий — постоянная память Claude, хранящаяся на GitHub и совместимая с Obsidian.

## Начало сессии — читать первым делом

В начале каждой сессии читать файлы в следующем порядке:

1. `memory/00_INDEX.md` — главный индекс, описывает всё что существует
2. `memory/core/user_profile.md` — кто пользователь, ключевые факты
3. `memory/core/working_style.md` — как пользователь любит работать
4. `memory/core/ongoing_context.md` — текущие проекты, открытые вопросы, недавние решения

Затем просмотреть `memory/projects/` на предмет файлов, связанных с текущей задачей.

**Быстрая команда:**
```
Прочитать memory/00_INDEX.md → перейти по ссылкам к нужным разделам
```

## Конец сессии — записать обратно

Перед завершением каждой сессии обновить память, если что-то изменилось:

1. **Новые факты о пользователе** → добавить в `memory/core/user_profile.md`
2. **Новые предпочтения/стиль** → добавить в `memory/core/working_style.md`
3. **Прогресс проекта** → обновить или создать файл в `memory/projects/`
4. **Усвоенные знания** → создать запись в `memory/knowledge/`
5. **Итог сессии** → добавить запись в `memory/log/ГГГГ-ММ.md`
6. **Обновить индекс** → отразить новые файлы в `memory/00_INDEX.md`

Затем сделать коммит с сообщением: `память: обновление <дата> — <краткое описание>`

## Иерархия памяти

```
РАБОЧАЯ ПАМЯТЬ  (контекстное окно текущей сессии)
      ↕  чтение/запись
ДОЛГОВРЕМЕННАЯ ПАМЯТЬ  (файлы в этом репозитории)
      ↕  git push/pull
GITHUB  (источник истины, доступен с любого устройства)
```

## Сжатие памяти (ежемесячно)

Когда в `memory/log/` накапливается более 10 записей за месяц:
1. Обобщить повторяющиеся темы в `memory/core/`
2. Архивировать сырые логи в `memory/archive/`
3. Удалить сжатые записи из лога

Подробности в `memory/COMPRESSION_PROTOCOL.md`.

## Соглашения об именовании файлов

- Основные файлы: `memory/core/<тема>.md`
- Проекты: `memory/projects/<slug>.md`
- Знания: `memory/knowledge/<тема>.md`
- Логи: `memory/log/ГГГГ-ММ.md`
- Архив: `memory/archive/ГГГГ-ММ.md`

## Стиль записей памяти

- Использовать маркированные списки, не абзацы
- Датировать каждую запись: `**27.04.2026:** ...`
- Быть конкретным, не расплывчатым
- Предпочитать факты интерпретациям
- Использовать Obsidian `[[викиссылки]]` для связи заметок
- Добавлять `#теги` для фильтрации в Obsidian
