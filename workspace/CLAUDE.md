## Общие правила работы

1. Всегда читай базу знаний `claude-memory-compiler` — там контекст текущих задач
2. Все документы для компании создавать в фирменном стиле ВольтМаркет
3. Инструменты пользователя: Obsidian, Excel, 1С
4. Рабочая ОС: Windows 10, Python доступен через `py`
5. Node.js не установлен — для docx использовать `python-docx`
6. PDF > 20 МБ читать через PyMuPDF (рендер в PNG), не через Read tool
